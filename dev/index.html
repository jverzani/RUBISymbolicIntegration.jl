RUBISymbolicIntegration

Documentation for RUBISymbolicIntegration.

This is basically the rules-based part of SymbolicIntegration.

The main function is integrate(f, x), which returns an antiderivative of f with respect to x. The rules are those of Rubi. Any symbolic type implementing TermInterface.jl can be used once an extension for it is loaded; extensions are included for SymEngine, SymbolicUtils (through Symbolics) and SimpleExpressions.

Examples with SymEngine

Load the package and SymEngine, and create some symbolic variables:

using RUBISymbolicIntegration, SymEngine
@vars x a b n

Polynomials and linear substitutions

integrate(3x^2 + 2x + 1, x)
x + x^2 + x^3
integrate((2 + 3x)^5, x)
(1/18)*(2 + 3*x)^6
integrate(1 / (2 + 3x), x)
(1/3)*log(2 + 3*x)

Symbolic parameters

Parameters may appear in the integrand. A rule applies only when its conditions hold; for $(a + bx)^n$ the rule requires $n \ne -1$, which a symbolic n is taken to satisfy:

integrate((a + b*x)^n, x)
(a + b*x)^(1 + n)/(b*(1 + n))
integrate(x^n * log(x), x)
-x^(1 + n)/(1 + n)^2 + x^(1 + n)*log(x)/(1 + n)

Exponentials, logarithms and trigonometric functions

Integration by parts:

integrate(x * exp(x), x)
x*exp(x) - exp(x)
integrate(x^2 * sin(x), x)
-x^2*cos(x) + 2*(x*sin(x) + cos(x))
integrate(atan(x), x)
x*atan(x) + (-1/2)*log(1 + x^2)

Substitutions:

integrate(log(x) / x, x)
(1/2)*log(x)^2
integrate(1 / (x * log(x)), x)
log(log(x))
integrate(x / sqrt(1 + x^2), x)
sqrt(1 + x^2)

Rational functions

integrate(1 / ((x - 1) * (x - 2)), x)
log(-2 + x) - log(-1 + x)
integrate((2x + 3) / (x^2 + 3x + 2), x)
log(2 + 3*x + x^2)
integrate(1 / (x^3 - x), x)
(1/2)*(log(-1 + x^2) - log(x^2))

Special functions

Some antiderivatives are not elementary. The answer then uses special functions: the sine integral $\operatorname{Si}(x)$, the exponential integral $\operatorname{Ei}(x)$ and the dilogarithm $\operatorname{Li}_2(x)$:

integrate(sin(x) / x, x)
Sinint(x)
integrate(exp(x) / x, x)
1.0*Expinti(x)
integrate(log(1 + x) / x, x)
-reli(2, -x)

With SymEngine these stay unevaluated functions, such as Sinint and reli (PolyLog.jl's $\operatorname{Li}_n$). With SimpleExpressions or Symbolics they are the functions of SpecialFunctions.jl, PolyLog.jl and HypergeometricFunctions.jl, so such an answer can be evaluated numerically.

Showing the steps

With verbose = true, integrate prints each rule as it is applied: its identifier, the integral it matched, the rule itself and what it gave. An integral that a rule does in turn is shown inside that rule's step. The identifier names the rule's section in RUBI; 3_1_2_2 is in section 3.1.2, (d x)^m (a+b log(c x^n))^p:

F = integrate(1 / (x * log(x)), x; verbose = true)
┌ rule 3_1_2_2 on ∫(1/(x*log(x)), x)
│   ∫((a + b * log(c * x ^ n)) ^ p / x, x)
│     if
│         !(contains_var(a, b, c, n, p, x))
│     => (1 / (b * n)) * substitute(∫{x ^ p}dx, x => a + b * log(c * x ^ n))
│ ┌ rule 1_1_1_1_1 on ∫(x^(-1), x)
│ │   ∫(1 / x, x) => log(x)
│ └ gives log(x)
└ gives log(log(x))

Checking an answer

Differentiate the antiderivative and compare it with the integrand:

f = x^2 * sin(x)
F = integrate(f, x)
expand(diff(F, x) - f)
0

SymEngine does not always reduce such a difference to 0, for instance when fractions would need combining. Checking at a value works in any case:

f = 1 / (x^3 - x)
F = integrate(f, x)
N(subs(diff(F, x) - f, x => 3))
0

When no rule applies

If no rule applies, the integral is returned unevaluated:

F = integrate(1 / (a + b * cos(x)), x)
∫((a + b*cos(x))^(-1), x)
RUBISymbolicIntegration.contains_int(F)
true
